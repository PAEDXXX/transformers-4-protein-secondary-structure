# An Introduction to Transformers in Biology

Problem: 
Given an amino acid sequence, find a way to reliably predict the corresponding secondary structure sequence. 

Initial Thoughts:

The first thing that came to mind was labeling this problem as a sequence to sequence (seq2seq) problem. Afterall, both the input and the output are sequences so it is logical to assume that secondary structure prediction is a seq2seq problem. In reality, the goal is to label each of the input amino acid sequences as part of a secondary structure. This entails that the output sequence be the same length as the input sequence. In other words, a one to one coresspondence. Token classification is the task of labeling or classifying characters in an input sequence as part of a distinct group. Each token, or amino acid residue, will be classified into a destinct category which represents a secondary structure. In the case of this problem, each amino acid would contriubte to the construction of a secondary structure, whether they be classified a helix, coil, or sheet. 

The next step would be defining a model that works well with the token classification and would able to understand how the relationship between amino acids in a seqnuence can influce secondary structure. A model needs to be able to absorb the full context of a sequence when determining how to best encode a token. Unidirectional context models like GPT are limited to referencing only previous tokens in a sequence when performing self attention. In protein structure prediction it is important to reference all tokens, before and after, in a sequence when coming up with an embedding. Afterall, structure can be influenced by residues from far away in the sequence. The Bidirectional Encoders Representations from Transfromers (BERT) model excels at referenceing tokens from both sides of sequences when encoding for a specific token (hence the name bidirectional). The specific model of choice was ProtBERT. ProtBERT is a model that has been pre-trained on a large dataset of protein sequences with the task of masked language modeling. Masked language modeling entails a basic understanding of the relationship different amino acids have with eachother in a sequence. The model was asked to predict a missing token in the sequence. The decision to use a pre-trained model instead of building a model from the groud up was made in the understanding that training such a model from scratch would have taken an amount of compute and time outside the current constraints. Using a pre-trained model essentially gives a head start on the accuracy of the model's parameters, meaning they are already tuned to understand intrasequence relationships and now just need to be pushed over the edge for understanding a down stream task such as secondary structure prediction.
