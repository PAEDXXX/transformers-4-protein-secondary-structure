This problem requires us to understand the intricate relationships between individual amino acid residues and how they impact secondary structure. We are looking for a pattern within the residues that gives us an improved chance of predicting the secondary structure. A piece of software that is good at comprehending patterns and using that understanding to make predictions would suit this task perfectly. Thankfully neural networks excel at tasks like this. A typical software program gives the computer a finite set of instructions to meet a goal. To predict the behavior of complex systems like protein folding it more effecient to use a neural network which has to flexibilty of understanding systems with many variables. 

It is easiet to think of a neural network as a mathamatical function. The function has weights and bias (called parameters) that can be thought of as coefficients of the input variable. For example, the 5 in this function is a parameter: f(x) = 5x + 2. Adjusting the parameters allows you to manipulate what the outputs are. In our problem, we want to input a sequence of residues and we expect the function, or neural network (NN), to output to correct secondary structures. In reality, the input sequences and structures are transformed into numerical values call matrices so that mathimatical operations can take palce on them. To keep things simple we won't go into the matrices yet. Going back to our function simplification, our goal is to find the coefficent (parameter) that gives us the closest output to our expected value. Let's go over the steps a neural network takes to achive this. 

The first step is called the feed forward. As the name implies, you feed your first sequence through the network. At this point the parameter are randomly initialized. The function will now be applied to your input and will output a certain value. This value is now compared to the expected value via a loss function. To keep things simple you can just think of the loss as the difference between the output and the expected value. 

The following step is called gradient descent. A gradient or derivative will be calculated that links the parameter to the loss. The gradient will tell you how changing the value of the parameter (currently random) will change the loss. Simply put, it gives you a direction to adjust the parameter to that will lower to loss to zero or close to it. Remember, when the loss is at zero the output value and the expected value are the same. 

Gradient descent is followed by back propagation. Back propagation is what actually applies the knowledge the gradinets gave us and now changes the parameters to lower the loss. Throught these steps we will be one step closer to our expected value. One of these cycles is called an epoch. When NNs are actually applied to problems they can become slightly more complicated, meaning more parameters and epochs, but the overall system works the same. 

The first thing that came to mind was labeling this problem as a sequence to sequence (seq2seq) problem. Afterall, both the input and the output are sequences so it is logical to assume that secondary structure prediction is a seq2seq problem. In reality, the goal is to label each of the input amino acid sequences as part of a secondary structure. This entails that the output sequence be the same length as the input sequence. In other words, a one to one coresspondence. Token classification is the task of labeling or classifying characters in an input sequence as part of a distinct group. Each token, or amino acid residue, will be classified into a destinct category which represents a secondary structure. In the case of this problem, each amino acid would contriubte to the construction of a secondary structure, whether they be classified a helix, coil, or sheet. 

The next step would be defining a model that works well with the token classification and would able to understand how the relationship between amino acids in a seqnuence can influce secondary structure. A model needs to be able to absorb the full context of a sequence when determining how to best encode a token. Unidirectional context models like GPT are limited to referencing only previous tokens in a sequence when performing self attention. In protein structure prediction it is important to reference all tokens, before and after, in a sequence when coming up with an embedding. Afterall, structure can be influenced by residues from far away in the sequence. The Bidirectional Encoders Representations from Transfromers (BERT) model excels at referenceing tokens from both sides of sequences when encoding for a specific token (hence the name bidirectional). The specific model of choice was ProtBERT. ProtBERT is a model that has been pre-trained on a large dataset of protein sequences with the task of masked language modeling. Masked language modeling entails a basic understanding of the relationship different amino acids have with eachother in a sequence. The model was asked to predict a missing token in the sequence. The decision to use a pre-trained model instead of building a model from the groud up was made in the understanding that training such a model from scratch would have taken an amount of compute and time outside the current constraints. Using a pre-trained model essentially gives a head start on the accuracy of the model's parameters, meaning they are already tuned to understand intrasequence relationships and now just need to be pushed over the edge for understanding a down stream task such as secondary structure prediction.
